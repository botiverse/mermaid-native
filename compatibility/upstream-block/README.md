Pinned revision `04ee3364045d6573f84034d3c9368cc50233a92f`. `run.py --upstream PATH --stdlib PATH` checks source hashes and runs the original 26 Jison consumer assertions unchanged against a built Native JAR. Native BlockDiagram supplies nodes, recursive children, columns, edges, styles/classes and width warnings. The bridge projects these to the original database API; warning strings originate in Native and are forwarded to the original logger.

The DOMPurify configuration assertion remains a mixed JavaScript configuration test: the projection invokes upstream sanitizeText with the current browser config. It is not Native sanitization coverage and must not be counted as a Native pass. Other results are parser/model boundary evidence, not pixel or general CSS parity. Native rendering covers the existing rectangular grid, nested composites, spaces, cardinal block arrows, edge labels and bounded fill/stroke/text styles. Additional upstream shapes, arbitrary CSS, browser HTML label rendering and exact upstream layout remain unclaimed. Columns are bounded to 512 to keep rendering finite; oversized spans produce Native warnings and clamp to their container for drawing.
